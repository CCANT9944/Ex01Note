# ex01 (Notes App)

A fully-featured Jetpack Compose Android application acting as a highly functional, offline-first Notes app!

## Features
- **Folders & Subfolders**: Organize your notes with a deeply nested folder structure.
- **Rich Note Types**:
  - **Free-Text Notes**: Write and format your thoughts.
  - **Checklists**: Keep track of tasks with interactive lists.
  - **S-Notes (Canvas)**: Draw, highlight, and type floating text directly onto a visual canvas.
- **App Widgets**: Pin your favorite notes to the home screen for quick access.
- **Theming**: Custom folder colors and dynamic UI elements. Light mode focused for optimum readability.
- **Trash/Recycle Bin**: Soft-delete items and restore them later.

## Tech Stack
- **UI**: Jetpack Compose (100% Kotlin)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Local Database**: Room (SQLite) with Kotlin Coroutines & Flows
- **Navigation**: Jetpack Compose Navigation

## Project Structure
The app operates on a clean, domain-driven package structure:
- `data/` - Room database setup, DAOs, Repositories, and Entity models (Note, Folder, NoteItem).
- `ui/screens/` - Main full-screen composables (Home, Folder Detail, Trash).
- `ui/editor/` - Note editing screens (Free-Text, Checklist, S-Note canvas).
- `ui/dialogs/` - Reusable modal dialogs modularized into `CommonDialogs.kt`, `FolderDialogs.kt`, `NoteDialogs.kt`, etc.
- `ui/components/` - Reusable UI elements modularized into `FolderCard.kt`, `NoteCard.kt`, `HomeTopAppBar.kt`, `EmptyStateCard.kt`, etc.
- `ui/theme/` - Color schemes, Typography, and Shapes.
- `widget/` - Android App Widget providers and configuration screens.

## Recent Updates & Optimizations
- **Free-Text Typing & Rendering Optimizations**: Completely eliminated typing latency and layout sluggishness on long notes by implementing:
  - *Fast Typing Path*: Added a fast diff check (`needsSanitization`) in `RichTextEditorController` to bypass heavy full-text normalization and tag parsing on standard plain-text keystrokes.
  - *Span Style Grouping*: Optimized visual text transformation in `RichTextRendering` to group consecutive identical styled characters into a single continuous `SpanStyleRange` rather than individual character spans, dropping text layout complexity from $O(N)$ to $O(1)$ style ranges.
  - *Primitive Array Offsets*: Replaced `MutableList<Int>` offset mappings with dynamic primitive `IntArray` collections to fully eradicate integer boxing/unboxing allocation overhead during typing.
- **S-Note Canvas Performance Enhancements**: Implemented key architectural canvas drawing optimizations:
  - *AABB Lasso Pruning*: Added spatial bounding-box intersection checks for drawings before performing exact winding-number computations, saving significant CPU cycles.
  - *Flat Coordinate Serialization*: Streamlined coordinates serialization to a flat list of doubles, reducing serialization payloads while retaining full backward compatibility with legacy JSON structures.
  - *Incremental Path Assembly*: Optimized active drawings by appending points incrementally using `lineTo` on cached path objects rather than rebuilding the full path on every touch event.
  - *Multi-Layer Canvas Rendering*: Split drawing rendering into static cache and active drawing overlay layers. Configured a shared `graphicsLayer(alpha = 0.99f)` parent constraint to support blending clears (`BlendMode.Clear`) without window background punching.
- **Modular Rich Text Engine Refactoring**: Refactored the monolithic, ~1600-line `RichTextMarkup.kt` file into five distinct, single-responsibility files (`RichTextConstants.kt`, `RichTextNormalization.kt`, `RichTextFormatting.kt`, `RichTextState.kt`, `RichTextRendering.kt`) under the `com.example.ex01.ui.editor` package. This drastically improves code organization, developer experience, and maintainability while maintaining 100% test suite compatibility.
- **Folder Detail Unified Grid & Cleanups**: Refactored the Folder Detail screen to eliminate the split "Items" layout, directly docking notes under subfolders within a unified `LazyVerticalGrid`. We completely purged the obsolete `FolderGrid` and `NoteGrid` components, leaning into clean inline section headers for peak scrolling performance.
- **Free-Text & SNote Refinements**: Adjusted standard free-text note editors to utilize properly scaled typography, ensuring regular note text sizes remain crisp and proportionate. In the S-Note Canvas, we finalized the removal of legacy "Add page" options from the toolbar since the workspace is now fully continuous, and successfully relocated the "Clear All" canvas action from the main toolstrip into the top-right 3-dots menu for a cleaner interface. We also engineered a pixel-perfect sub-grid extrapolation algorithm that extracts integer-rounded `TextLayoutResult` heights, completely eliminating visual drift and guaranteeing seamless mathematical alignment when appending or stacking new text blocks.
- **Modular Codebase Strategy (Refactor)**: Successfully eliminated massive monolithic UI files (`AppDialogs.kt`, `NoteComponents.kt`) by extracting and distributing structurally related UI boundaries (cards, top bars, modular dialog chunks) into independent files utilizing custom deterministic recursive AST regex scripts (`split_final.py`). - **Smart Render Culling & State Fix**: Navigation "pop-back" jank is gone!
